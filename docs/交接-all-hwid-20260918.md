## hwid_lock.c 选型（重要）

用 5-key 增强版（原 sm8850-hwid/5x-hwid 版），**不用** sm8650/8750-hwid 的旧 2-key 版：
- 旧版 `#include <linux/panic.h>` —— 5.10/5.15 树无此头（6.x 才拆分），会直接编译失败
- 增强版只用 `kernel.h`（panic/panic_timeout 在 5.10-6.12 的 kernel.h 里）
- 增强版逐 key 全比对（chipid/cpuid/emmcid/serialno/oplusboot.serialno），任一命中即放行；旧版只查 2 个 key

## 加设备流程

1. 设备端（原厂内核）跑 `sh hwid/probe_hwid.sh [预期id]` → `/sdcard/hwid_probe.log`
2. 取**原始值**（不要信识别脚本格式化输出），确认来源 key
3. 填 `hwid/allowlist.txt`（`^[0-9a-z._:-]{4,128}$`，超长 ID 必须原值逐字符一致）
4. 提交推送 → 触发构建 → **刷入前确认设备在 allowlist**（不在会 panic 不开机）
